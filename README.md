# NLP_gender_voice_clssification

Bu loyiha o'zbekcha nutq yozuvidan gapirayotgan odamning erkak yoki ayol ekanini aniqlaydi. Model Mozilla Common Voice'ning o'zbekcha datasetida o'qitilgan. Audiodan mel-spektrogramma xususiyatlari ajratiladi va Keras neyron tarmog'i orqali jins bashorat qilinadi. Gradio interfeysi orqali audio fayl yuklash yoki mikrofonda gapirib, natijani ehtimollik bilan ko'rish mumkin.
